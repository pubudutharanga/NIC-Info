How Old NIC to New NIC Conversion Works

1

Year expands from 2 to 4 digits. The old format uses the last two digits of the birth year (e.g. 85 = 1985). The new format uses all four digits (1985).

2

Day-of-year code stays the same. Both formats use a 3-digit number (001–366 for males, 501–866 for females) to encode the birthday and gender in a single field.

3

Serial gets a leading zero, letter becomes a digit. The old 4-digit serial (e.g. 0159) becomes 5 digits (00159). The V/X voter suffix is replaced by a numeric check digit.
